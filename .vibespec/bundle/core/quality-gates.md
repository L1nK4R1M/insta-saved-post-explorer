# Quality Gates

## Gate 1: Ready to implement

- Change mode selected.
- Existing system inspected.
- Observable acceptance criteria defined.
- Material ambiguities resolved or explicitly deferred.
- Test seams identified.
- Critical work has risks, rollback, and approval gates.

## Gate 2: Slice complete

- Requested behavior implemented without unrelated scope.
- Focused test first demonstrated the missing or broken behavior when applicable.
- Focused tests pass.
- Static checks for touched code pass.
- No debug instrumentation or temporary artifacts remain.

## Gate 3: Change complete

- Original scenario passes.
- Full relevant test suite passes.
- Build/package checks pass where applicable.
- Traceability is complete for Standard and Critical work.
- Spec and quality reviews are addressed or accepted.
- Durable documentation matches the resulting system.
- Final report lists commands, outputs, limitations, and unverified areas.
