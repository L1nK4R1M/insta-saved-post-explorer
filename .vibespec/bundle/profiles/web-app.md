# Web Application Profile

Load this profile only for browser-delivered applications.

## Additional gates

- Accessibility: keyboard navigation, focus, labels, contrast, and semantic structure.
- Responsive behavior at declared breakpoints.
- Loading, empty, error, offline, and partial-data states.
- Browser compatibility and performance budgets.
- Authentication and authorization enforced server-side.
- End-to-end tests at critical user journeys, not every visual detail.
- Client telemetry must exclude secrets and sensitive content.
