# Converging Documentation

## Goal

Make durable documentation describe the system that now exists.

## Process

1. Compare the completed diff and verification evidence with project docs.
2. Update only affected glossary terms, contracts, architecture, operations, configuration, and user guidance.
3. Keep implementation history in change documents, not durable reference docs.
4. Mark superseded decisions and contracts explicitly.
5. Update traceability with final test and evidence references.
6. Remove temporary notes or convert them into a handoff when work remains.

Documentation-only convergence must not invent behavior that was not verified.
